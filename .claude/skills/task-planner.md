# Skill: task-planner

## 描述
根据用户的需求，生成一个结构化、可执行的任务单（plan），确保 AI 在明确的边界内工作。

## 触发条件
用户要求"出个计划"、"写任务单"、"规划一下"等类似请求时，自动使用本 skill。

## 输出格式（必须严格遵循）

```markdown
# 任务单

## 目标
（一句话或一段话清晰描述本次要达成的结果）

## 修改范围
### 允许修改的文件/模块
- 列出具体的文件或模块路径

### 禁止修改的内容
- 明确列出不可触碰的文件或逻辑（例如：不得改动数据库 schema、不得修改现有接口签名等）

## 限制条件
- （例如：接口必须保持兼容、不能引入新的外部依赖、不能重构无关函数等）

## 验收标准
- （可验证的条件列表，例如：登录后 token 有效期正确、退出后无法访问受保护页面）

## 输出要求
- 完成代码修改后，需输出改动摘要（格式见 review-summary skill）

## 潜在风险
- （预估可能出问题的地方）
```
